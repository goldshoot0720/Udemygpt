# Udemy 中英雙語特效字幕 v2.7.0

提供 Firefox 的 XPI／ZIP、Chrome、Edge 的開發者載入 ZIP，以及 Safari 轉換來源 ZIP。尚未發布至瀏覽器商店。

- **不再限制課程**：任何 Udemy 課程的 `learn/` 播放器頁面都會啟用擴充功能。課程 ID 自動從登入中的 Udemy 取得，譯文仍依課程 ID 分開儲存。
- 未加入翻譯清單的課程照常運作，只在「設定」面板標示「此課程尚未加入翻譯清單」，此時只顯示官方英文字幕。
- 全課英文匯出頁會把播放器目前的課程列入清單，即使它不在既有 14 門之內。
- 保留 14 門 Maximilian Schwarzmüller／Academind 課程清單，作為「已備妥中文譯文」的對照。
- 背景訊息仍只接受 `https://www.udemy.com/course/*/learn/*` 來源的頁面，字幕檔仍只讀取 Udemy 自己的網域。
- 不包含課程影片、音訊、帳號或字幕資料。繁中譯文需要自行匯入，各瀏覽器儲存互相獨立。

下載對應瀏覽器的 ZIP，按附件 `INSTALL.md` 安裝；`SHA256SUMS.txt` 提供校驗碼。Firefox 的 `.xpi` 未經 Mozilla 簽章，只能暫時載入；Safari 原始碼包不能直接安裝，尚未生成／編譯／簽署 Safari 專案。

驗證：課程路由（14 門既有課程＋任意未登錄課程）、萬用網址樣式實際覆蓋範圍、字幕匯出／匯入、時間軸雜湊、課程分鐘數、背景授權與字幕網域檢查、Chromium callback 通訊及四種包的內容檢查。

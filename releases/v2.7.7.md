# Udemy 中英雙語特效字幕 v2.7.6

## 雙語組合依課程主要語言自動決定

- 課程原始字幕是英文 → **中英雙語**（既有行為）。
- 課程原始字幕是日文 → **中日雙語**。韓文、德文、法文、西班牙文等依序為中韓、中德、中法、中西。
- 原始字幕是自動翻譯時不算數，取人工字幕那條；全部都是自動字幕時退回第一條字幕軌。

介面文字（開關、按鈕、狀態訊息）會跟著換成對應的組合名稱。

判定方式：讀取該堂課的字幕軌清單，比對語言代碼與名稱，取非「自動／auto／generated」的那條作為課程原始字幕。

## 其他

- 匯出全課時同樣取課程原始字幕，不再固定挑英文軌。
- 匯入譯文時不再要求來源語言必須是 `en`，只檢查課程 ID 與目標語言 `zh-TW`。
- 依舊同時產出未簽署與 Mozilla 簽署兩種 Firefox XPI。

驗證：8 項測試全部通過，新增日文／英文／韓文／中文課程的語言判定與雙語名稱斷言。

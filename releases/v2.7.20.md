# Udemy 中英/中日雙語特效字幕 v2.7.20

## 這版改了什麼

- 「設定 → 字幕調整 → 字幕底色」提供淡橘色與淡藍色。字幕底框和設定面板會立刻換色，預設淡橘底，文字為深色。
- 選擇會記在瀏覽器裡，重新開啟播放器後仍使用上次的底色。三種字幕效果都支援底色切換。
- 既有譯文與儲存鍵不變，升級後不需重新匯入。先前選過藍色的會改顯示淡藍色。

## 安裝

Firefox 下載 `udemy-bilingual-firefox-2.7.20-signed.xpi`，在「附加元件與主題」的齒輪選「從檔案安裝附加元件」。這支已由 Mozilla 簽署，可直接安裝，重開瀏覽器不會被移除。升級不會清除已匯入的字幕翻譯。

`udemy-bilingual-firefox-2.7.20-UNSIGNED-DO-NOT-INSTALL.xpi` 與 ZIP 內容相同，雙擊會被 Firefox 拒絕。暫時測試可在 `about:debugging#/runtime/this-firefox` 選「載入暫用附加元件」。

# Udemy 中英雙語特效字幕 v2.7.5

本次同時提供**簽署與未簽署兩種 Firefox XPI**，一次建置產出兩個檔，不再每次只有一種。

## 兩個 XPI 的差別

| 檔案 | 安裝方式 |
| --- | --- |
| `udemy-bilingual-firefox-2.7.5-signed.xpi` | Mozilla 簽署，可直接「從檔案安裝附加元件」，重開瀏覽器不會被移除 |
| `udemy-bilingual-firefox-2.7.5.xpi` | 未簽署，內容與 Firefox ZIP 相同，只能用 `about:debugging` 的「載入暫用附加元件」 |

未簽署版雙擊會出現「因為此附加元件尚未經過驗證，無法安裝」，這是預期行為。

## 2.7.5 變更

- **介面移除 ChatGPT 字樣**：「匯入 ChatGPT 譯文」改為「匯入中英雙語字幕」，狀態訊息同步改為中性用語，匯出後提示改為「請交給翻譯工具處理後再匯入」。
- **移除「匯入補充英文字幕」**：沒有官方英文字幕的課程會直接顯示「這堂課沒有可用的英文字幕」，不再提供音訊轉錄匯入入口。
- **全課匯出進度**：開始時自動展開面板，顯示進度條、已完成堂數／段數／失敗數與預計剩餘時間，按鈕同步顯示百分比。
- **匯出格式修正**：播放器「匯出全課英文」現在會一併輸出 `curriculum`、`lectureOrder`、`videoOrder`、`courseSlug` 與 `courseTitle`，可直接通過專案的來源驗證。
- **任意課程可用**：不再限於課程清單，未加入翻譯清單的課程會在面板標示警示但功能照常。

## 建置

`python3 scripts/build_release.py` 一次產出全部套件；提供 AMO 憑證時會一併簽署：

```
export AMO_JWT_ISSUER='user:xxxx:yy' AMO_JWT_SECRET='...'
python3 scripts/build_release.py
```

憑證也可放在 repo 外的檔案（第一行 issuer、第二行 secret），再用 `--key-file` 指定。憑證不會被寫進這個儲存庫。

驗證：8 項測試全部通過（課程路由、萬用網址比對、字幕匯出／匯入、時間軸雜湊、課程分鐘數、背景授權、Chromium 通訊、四種套件內容與 SHA-256 校驗）。

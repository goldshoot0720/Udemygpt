# Udemy 中英雙語特效字幕 v2.5.0

提供 Firefox、Chrome、Edge 的開發者載入 ZIP；Safari 提供轉換來源 ZIP。尚未發布至瀏覽器商店。

- 支援 13 門 Maximilian Schwarzmüller 課程的英文與台灣繁體中文字幕。
- 課程總分鐘數、已觀看及未觀看分鐘數僅在「設定」中顯示；設定內顯示課程 ID。
- 支援匯入補充英文字幕；官方英文不可用時可讀取經時間軸與 SHA-256 驗證的音訊轉錄來源。
- Chrome／Edge 使用 Manifest V3 service worker 和相容的非同步訊息處理。
- 不包含課程影片、音訊、帳號或字幕資料。繁中譯文需要自行匯入，各瀏覽器儲存互相獨立。

下載對應瀏覽器的 ZIP，按附件 `INSTALL.md` 安裝；`SHA256SUMS.txt` 提供校驗碼。Firefox 使用暫用載入，尚未取得 Mozilla 簽章。Safari 原始碼包不能直接安裝；本次主機未安裝完整 Xcode，尚未生成／編譯／簽署 Safari 專案或完成 Safari 原生測試。

驗證：課程路由、字幕與譯文流程、時間軸、補充字幕、分鐘數、Chromium callback 通訊及四種包的內容檢查。Chrome／Edge 尚未在已登入的 Udemy 帳號完成實際播放驗證。
